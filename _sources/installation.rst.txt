Installation
============

There are several ways to install resplotlib:

* Use `uv <https://docs.astral.sh/uv/>`__ to install the package from `PyPI <https://pypi.org/project/resplotlib/>`__:

   .. code-block:: bash

      uv add resplotlib  

* Use `pip` to install the package from `PyPI <https://pypi.org/project/resplotlib/>`__:

   .. code-block:: bash

      pip install resplotlib

* Use `conda` to install the package from `conda-forge <https://anaconda.org/conda-forge/resplotlib>`__:

   .. code-block:: bash

      conda install -c conda-forge resplotlib

* Install the package from source by cloning the repository and using `uv` to install it:

   .. code-block:: bash

      git clone https://github.com/Ruben-White/resplotlib.git c:\...\resplotlib
      cd c:\...\resplotlib
      uv sync
